                    ATRIUM SILLAGE - DOCUMENTATION
================================================================================

1. DESCRIPTION DE L'APPLICATION
================================================================================

Atrium Sillage est un jeu d'enquête policière interactif en ligne qui se déroule
dans un hôtel Art déco des années 1930.

- Framework : Next.js 15 (React)
- IA : AI SDK Vercel avec Google Gemini
- Modèle actuel : gemini-flash-lite-latest
- Serveur : http://localhost:3005 (variable selon disponibilité)
- Style : Interface pixel art avec fenêtres draggable style Habbo

Le jeu génère des affaires de meurtre uniques avec des PNJ IA qui mentent,
ont des secrets, et se déplacent en temps réel.


2. PRINCIPE DU JEU
================================================================================

OBJECTIF
--------
Vous êtes un détective. Un meurtre a été commis à l'hôtel. Vous devez trouver
LE COUPABLE parmi les 4 suspects avant la fin des 12 tours.

MÉCANIQUES DE JEU
-----------------

1. OUVRIR UNE AFFAIRE
   - Cliquez sur "Ouvrir une affaire" pour commencer
   - L'IA génère une affaire unique (4 suspects, 6 indices, mobile, méthode)
   - Si l'IA échoue, utilise le fallback "Le sillage de minuit"

2. EXPLORER LES PIÈCES
   - 6 pièces disponibles : Bureau, Bibliothèque, Jardin d'hiver, Salon,
     Grand hall, Cuisines
   - Cliquez sur Navigator → choisissez une pièce → cliquez "Go"
   - Coûte 1 tour
   - Déplacement aussi possible via WASD dans la vue isométrique

3. FOUILLER POUR TROUVER DES INDICES
   - Dans une pièce, cliquez "Fouiller" dans le Navigator
   - Vous trouvez des indices physiques (ex: "Flacon brisé")
   - Coûte 1 tour
   - 6 indices au total à trouver (3 cachés dans les pièces, 3 détenus par les PNJ)

4. INTERROGER LES SUSPECTS
   - Cliquez sur un PNJ (personnage coloré) dans la vue isométrique
   - Posez des questions en français
   - L'IA répond en personnage (elle peut mentir !)
   - Si vous insistez, elle peut révéler des indices qu'elle détient
   - Coûte 1 tour par question
   - Les suspects peuvent quitter la pièce si trop stressés

5. ACCUSER
   - Quand vous pensez savoir qui est le coupable, cliquez "Accuser"
   - Sélectionnez le suspect
   - Expliquez votre raisonnement (mobile, méthode, indices)
   - Clôt l'affaire
   - Épilogue généré par l'IA

INTERFACE
----------
- Header : titre, pièce actuelle, tours restants, nom de l'affaire
- Vue centrale : vue isométrique de la pièce avec PNJ cliquables
- Navigator : changer de pièce + fouiller
- Dossier : voir les indices trouvés + journal des événements
- Settings : changer votre nom de détective

ASTUCES
-------
- Les suspects ont des secrets et mentent
- Le "Director" fait bouger les suspects entre les pièces
- Le niveau de stress d'un suspect augmente quand vous le pressez
- Au moins 3 indices mènent au vrai coupable
- Les suspects peuvent avoir des alibis contradictoires


3. L'AGENTIQUE DANS LE JEU
================================================================================

L'agentique intervient à 2 endroits clés : l'interrogatoire des PNJ et le
Director qui fait vivre le manoir.

3.1 AGENT PNJ (INTERROGATOIRE)
-------------------------------
Fichier : app/api/interrogate/route.ts

Quand vous interrogez un suspect, ce n'est pas un simple chatbot. C'est un
agent avec outils (ToolLoopAgent).

OUTILS DISPONIBLES :
- revealClue : Révéler un indice que le suspect détient
  → Utilisé si vous faites confiance ou si le suspect est coincé
- setComposure : Mettre à jour le niveau de stress (0-100)
  → Monte si vous le pressez, baisse si vous le mettez à l'aise
- leaveRoom : Quitter la pièce pour se réfugier ailleurs
  → Utilisé si le stress dépasse 75 et vous êtes agressif

COMPORTEMENT DE L'AGENT :
- Lit votre question
- Décide s'il doit mentir ou dire la vérité
- Utilise des outils en fonction du contexte
- Répond en personnage avec sa propre voix
- Protège son secret jusqu'au bout

EXEMPLE DE DIALOGUE :
Vous: "Qu'avez-vous vu à 23h40 ?"
Agent: [réfléchit] [utilise setComposure(stress: 30)]
      "J'étais au bureau en train de rédiger le registre."
Vous: "Mentez ! On vous a vu au hall près du corps !"
Agent: [réfléchit] [utilise revealClue(c5)]
      "D'accord... j'ai vérifié le buffet, mais je n'ai rien fait."

3.2 AGENT DIRECTOR
------------------
Fichier : app/api/director/route.ts

Le Director est un agent qui fait vivre le manoir entre vos tours.

OUTILS DISPONIBLES :
- moveSuspect : Déplacer un suspect vers une autre pièce
  → Les suspects stressés fuient la pièce du détective
- hideClue : Le coupable cache un indice physique en secret
  → Seulement si c'est le coupable, avec parcimonie
- ambientEvent : Créer une ambiance perceptible
  → Ex: "Un éclair illumine le hall", "Une porte claque"

COMPORTEMENT DE L'AGENT :
- Voit où sont tous les suspects
- Connaît leur niveau de stress
- Décide des actions à faire (1 à 3 par tour)
- Génère des narrations style roman noir
- Ne révèle jamais l'identité du coupable

EXEMPLE D'ACTION :
État: Léandre a stress 80, il est dans le hall avec vous
Agent Director: [réfléchit] [utilise moveSuspect(Léandre → Bibliothèque)]
Narration: "Léandre s'esquive vers la bibliothèque, un regard inquiet."

POURQUOI C'EST AGENTIQUE ?
--------------------------
Ce n'est pas juste de la génération de texte. Les agents :
- Prennent des décisions basées sur l'état du jeu
- Exécutent des actions via des outils
- Ont des objectifs (le PNJ veut protéger son secret, le Director veut créer du suspense)
- Réagissent dynamiquement à ce que vous faites

C'est de l'IA qui joue un rôle actif dans le jeu, pas juste qui répond à des questions !


4. CONFIGURATION TECHNIQUE
================================================================================

MODÈLE IA ACTUEL
----------------
- Provider : Google AI (@ai-sdk/google)
- Modèle : gemini-flash-lite-latest
- Clé API : Stockée dans .env.local (GOOGLE_GENERATIVE_AI_API_KEY)
- Fallback : Affaire "Le sillage de minuit" si l'IA échoue

API ROUTES
----------
- /api/case → Génère une nouvelle affaire (structure + indices + solution)
- /api/interrogate → Dialogue avec les PNJ (ToolLoopAgent avec outils)
- /api/director → Fait vivre le manoir (déplacements suspects, ambiance)
- /api/accuse → Génère l'épilogue final

DÉMARRAGE
---------
1. Ouvrir un terminal dans le dossier du projet
2. Lancer : npm run dev
3. Ouvrir le navigateur sur http://localhost:300X (port indiqué dans le terminal)
4. Cliquer "Ouvrir une affaire"
5. Jouer !

SI L'IA NE RÉPOND PAS
--------------------
- Vérifier que .env.local contient la clé API
- Vérifier les logs du serveur pour les erreurs
- Le fallback s'active automatiquement si l'IA échoue
- Le jeu reste jouable avec l'affaire de secours


5. AFFAIRE DE SECOURS (FALLBACK)
================================================================================

Titre : "Le sillage de minuit"

VICTIME : Albin Veyrier, collectionneur de parfums rares

SUSPECTS :
1. Hélène Marchal - Directrice de l'hôtel
2. Léandre Veyrier - Neveu endetté
3. Iris Delambre - Parfumeuse invitée
4. Otto Kranz - Majordome de nuit

COUPABLE : Iris Delambre (avec plagiat de formule)
MOBILE : Albin allait publier la preuve du plagiat
MÉTHODE : Cyanure dans le flacon de Sillage Noir

Cette affaire est utilisée automatiquement si l'IA ne peut pas générer une
nouvelle affaire.


6. RÉSUMÉ RAPIDE
================================================================================

- But : Trouver le coupable en 12 tours
- Actions : Explorer, fouiller, interroger, accuser
- Agentique : PNJ avec outils (révéler indices, stress, fuite) + Director (ambiance, déplacements)
- IA : Google Gemini gemini-flash-lite-latest
- Interface : Vue isométrique style Habbo avec fenêtres draggable
